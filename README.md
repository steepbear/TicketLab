# TicketLab — Лаборатория билетов

Прототип сервиса подарочных билетов: пользователь вставляет ссылку на мероприятие Яндекс Афиши, сайт извлекает **оригинальную афишу** и показывает её без генерации и подмены изображения.

## Рабочая версия

https://ticket-lab-afisha.slopedgazelle4.chatgpt.site

Сайт пока доступен только владельцу через ChatGPT.

## Что реализовано

- Ввод ссылки на мероприятие `https://afisha.yandex.ru/...`.
- Серверное получение HTML события и извлечение URL оригинального изображения (`background: url(...)`, `og:image` и другие признаки).
- Отображение афиши, названия мероприятия и площадки.
- Возможность открыть оригинал или скопировать ссылку.
- Сообщения об ошибке без подстановки похожих картинок.

## Архитектура

- `worker/index.js` — единый серверный Cloudflare Worker: HTML/CSS/JS интерфейс и endpoint `GET /api/event?url=...`.
- `scripts/build.sh` — сборка дистрибутива для хостинга Sites.
- `scripts/validate-artifact.mjs` — проверка сборки.
- `.openai/hosting.json` — конфигурация существующего сайта Sites, без ключей и паролей.

Node.js достаточно для локальной проверки кода:

```bash
node --check worker/index.js
npm run build
npm run validate
```

Для обращения к Яндекс Афише Worker должен иметь серверный HTTP-доступ. GitHub Pages не умеет выполнять серверную часть этого проекта.

## Дальнейшие задачи

1. Проверка извлечения афиш на разных типах мероприятий.
2. Два варианта компоновки: вертикальное изображение слева + данные справа; широкое изображение сверху + данные снизу.
3. Редактирование даты, времени, площадки и имени получателя.
4. Генерация PDF для печати.

Подарочный билет — только оформление подарка; вход осуществляется по оригинальному билету. Для коммерческого использования изображений нужно отдельно выяснить условия и права правообладателей.

**Решение по физической форме:** на данном этапе только цифровые макеты, без отрывного корешка и покупки билетного принтера.
